# hermes-astro

Натальные карты и транзиты на Python через Swiss Ephemeris (pyswisseph). Локально, бесплатно, точность эфемерид ~0.1".

## Возможности

- **natal_chart.py** — натальная карта: 13 точек (Солнце…Плутон, Сев. Узел, Хирон, Лилит), 12 систем домов (по умолчанию Плацидус), мажорные аспекты с орбисами, JSON-вывод.
- **transits_now.py** — текущие транзиты к натальной карте, сортировка по точности орбиса.

## Установка

```bash
pip install pyswisseph
# файл эфемерид для Хирона (остальные планеты считаются по Moshier без файлов):
mkdir -p ~/.hermes/ephe
curl -o ~/.hermes/ephe/seas_18.se1 https://raw.githubusercontent.com/aloistr/swisseph/master/ephe/seas_18.se1
```

## Использование

```bash
python3 natal_chart.py    # натальная карта (данные захардкожены — см. ниже)
python3 transits_now.py   # транзиты на текущий момент
```

## Настройка под себя

В начале скриптов поменяйте:

- `natal_chart.py`: `Y, M, D`, `UT` (часы UTC), `LAT`, `LON`, систему домов (`b'P'` = Плацидус, `b'W'` = целые знаки, `b'K'` = Кох…)
- `transits_now.py`: словарь `NATAL_LON` (свои натальные долготы в формате `"10°00' Козерог"`)

## Важно (дисклеймер)

Астрономические расчёты точны (Swiss Ephemeris). Интерпретации аспектов — традиция астрологии, научной доказательной базы не имеет. Инструмент для рефлексии и развлечения, не для принятия решений.
